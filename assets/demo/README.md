# Demo album covers

Original artwork for LavaTUI's invented `--demo` songs. Generated with
GPT Image 2.5 Sunburst through Venice (`gpt-image-2-5-sunburst`), then
reduced to 400 × 400 JPEGs. The exact prompts and generation settings
are in [prompts.json](prompts.json). No existing artwork was supplied.

| File | Invented artist / album | Subject |
| --- | --- | --- |
| `heat-rises-bloom.jpg` | The Paraffins / Heat Rises | An amber flower above a volcanic ridge |
| `heat-rises-moons.jpg` | The Paraffins / Heat Rises | Two violet moons joining above a pool |
| `lamplight-window.jpg` | Wax and Wane / Lamplight | A warm window among blue night foliage |

The first two are alternate sleeves for the same invented album, used
for “Slow Rise” and “Blob Merge” respectively. “Warm Light Falling” uses
the window sleeve. The art is embedded in the binary; demo playback
does not call Venice or download the images.
