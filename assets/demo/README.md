# Demo album cover

Original artwork shared by LavaTUI's three invented `--demo` songs.
Generated with GPT Image 2.5 Sunburst through Venice (`gpt-image-2-5-sunburst`), then
reduced to one 400 × 400 JPEG. The exact prompt and generation settings
are in [prompts.json](prompts.json). No existing artwork was supplied.

| File | Invented artist / album | Subject |
| --- | --- | --- |
| `suspended-melt.jpg` | Wax and Wane / Suspended Melt | Sage and coral wax blobs inside a tapered lamp outline, with risograph grain |

This was cover 09 in the user's candidate selection. All three demo songs
use this sleeve; their existing titles, artists, albums and lyrics stay
unchanged, so the sleeve's printed name differs from the playing track's
metadata. The image was resized with no colour adjustment. The art is
embedded in the binary; demo playback does not call Venice or download it.
